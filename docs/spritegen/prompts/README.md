# Start-Prompts

Jeden Prompt komplett in eine neue Claude-Code-Sitzung mit Zugriff auf dieses Repo kopieren. `<BUDGET>` durch den Betrag für die Sitzung ersetzen (Richtwert steht im Fahrplan).

Alle Prompts verweisen auf `docs/spritegen/AGENTS.md`. Dort stehen die Regeln gegen Abkürzungen, damit sie nicht in jedem Prompt wiederholt werden müssen.
