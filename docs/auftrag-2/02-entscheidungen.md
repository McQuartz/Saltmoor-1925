# Entscheidungen auf einen Blick

Abgestimmt mit Philip am 2026-11-04 (wörtlich in [00-philip.md](00-philip.md)).

| Thema | Entscheidung |
|---|---|
| Basis | `main` mit `more-cards` (PR #12 gemergt): Grundkarten, Vollbild |
| Deckaufbau | Kerben und Handgriffe: Items tragen Karten, Handgriffe werden gelernt, eingeritzt und nehmen den Stoff des Items an ([04-deckbau.md](04-deckbau.md)) |
| Gute plus schlechte Karte | keine Kernmechanik, höchstens 5 Items als Würze |
| Grundkarten | werden zu Start-Handgriffen in den Startitems |
| Kämpfe | geben immer Gold **und** eine Handgriff-Wahl, schwere Kämpfe und Wächter mehr |
| Boss-Beute | Reliquie aus 3 |
| Energie und Kosten | mehr Wege (Handgriffe, Funke, Fanal, Eigenschaften, seltene Reliquien), Schleifen senkt Kosten dauerhaft |
| Items verkaufen | ja, beim Krämer, 40 % |
| Run-Länge | 6 Ebenen plus Wächter je Akt I bis IV |
| Akte | bleiben fünf, jeder Akt bekommt mehrere Biome, Wahl zwischen zweien |
| Neue Biome | 10 (Fabrik, Kurhaus, Nachtzug, Kloster, Grotte, Wald, Gezeitenwerk, Walkathedrale, Glasmeer, Ufer), Pforte neu |
| Mengen | etwa 50 neue Gegner, 12 neue Bosse, etwa 90 Ereignisse insgesamt |
| Sprites | der Agent zeichnet wie in Auftrag 1 selbst per Skript, mehr Aufwand je Figur, Qualität mindestens wie bisher, keine Abkürzungen ([06-ki-bilder.md](06-ki-bilder.md)) |
| Steam-Regel | für diesen Auftrag zurückgestellt |
| Klang | weiter ohne KI |
| Windgestalt | wird überarbeitet, darf ersetzt werden, wenn das Konzept stärker ist |
| Pforte | neu entworfen (kein Science-Fiction), leichter (höchstens 35 % der Niederlagen) |
| Synergien und Builds | sechs Archetypen von Claude konzipiert, Agent baut und prüft mit Build-Bots |
| UI-Punkte | alle aus [07-ui-und-gefuehl.md](07-ui-und-gefuehl.md), ohne weitere Abstimmung |
| Musik | bleibt, nur längerer Aufbau beim Boss |
| Merge | nur nach Philips Blick auf den Stand |
